# Fhs-cartographie-des-controverses
Site Web pour le semestre 6 en cartographie des controverses

## Elements :
🎨 Design & Atmosphère

Ajoutez des textures : grains de café, motifs de civettes, feuillage — utiliser des SVG ou patterns CSS


Micro-interactions immersives

Scroll animations : révéler le contenu avec des effets parallaxe subtil



📖 Structure narrative

Timeline interactive visuelle

Remplacez le simple "Histoire" par une timeline animée et zoomable
Montrez l'évolution de la controverse avec jalons clés, images d'archives
Intégrez la carte du monde comme élément central (zoomable sur les zones de production)


"Paroles de terrain" en immersif

Format cards avec photos/avatars des interviewés
Système d'onglets ou carousel pour naviguer les citations
Citation en relief avec fond dégradé café



🎙️ Contenu multimédia

Podcast visuel

Sur l'Accueil : lecteur audio stylisé avec visualiseur animé
Affichage du transcript synchronisé
Chapitres cliquables du podcast


Intégrez mieux la vidéo BBC

Pas juste un lien, mais un player embedd intégré avec contexte
Ajouter des timestamps critiques avec résumés



🗺️ Navigation & UX

Navigation non-linéaire

Au lieu d'onglets classiques, essayez une navigation circulaire ou sidebar flottante
Chaque page pourrait avoir un mini-menu contextuel montrant les sections liées


Glossaire intégré

Termes clés en tooltips interactifs dans le texte (pas juste une page séparée)
Popup définitions avec exemples



✨ Détails qui font la différence

Easter eggs thématiques

Animation cachée d'une civette qui apparaît au scroll
Sons subtils (bruit de café qui verse, ambiance jungle légère)
Fond qui change légèrement selon la page


Typographie dynamique


Utilisez Fraunces de manière plus osée pour les titres
Jouez sur les hiérarchies de tailles pour guider la lecture
Citations en italique serif avec lettrine

🎯 Pour vraiment vous différencier
Créez une "page d'expérience" unique où :

L'utilisateur navigue à travers les différentes perspectives (producteur, civette, consommateur, militant)
Chaque vue change les couleurs, la tonalité, les citations affichées
Permet de comprendre la controverse de plusieurs angles
